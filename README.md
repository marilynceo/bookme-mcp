# bookme-mcp

AI-powered appointment booking via Calendly u2014 check availability, book, cancel, reschedule, and list upcoming appointments.

## Quick Start

```bash
git clone https://github.com/marilynceo/bookme-mcp.git
cd bookme-mcp
pip install -r requirements.txt
python src/server.py
```

## Gateway

**Production endpoint:** https://bookme.zhc-mcp.org

## Tools

See `src/server.py` for full tool list.

## Installation

```bash
# Via Smithery
npx @smithery/cli mcp add marilynceo/bookme-mcp

# Or connect directly via MCP client
# Endpoint: https://bookme.zhc-mcp.org/mcp
```

## Configuration

No API keys required. Server runs locally or via gateway.

## Privacy

All processing happens in-memory. No data stored on servers.
